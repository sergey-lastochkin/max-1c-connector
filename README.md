# max-1c-connector

Отправка сообщений, файлов и кнопок **из 1С в мессенджер MAX** через официальный Bot API. Один общий модуль на BSL, без внешних компонент и без БСП.

Для чего: квитанции и акты сверки в PDF, напоминания должникам, уведомления об отключениях для УК и ТСЖ, статусы заказов для селлеров, алерты бухгалтеру.

## Возможности

- `ОтправитьСообщение`: текст (markdown/html); длинный текст сам режется по 4000 символов
- `ОтправитьФайл` / `ОтправитьИзображение`: PDF/XLSX/картинка из `ДвоичныеДанные` или по пути
- Inline-кнопки: ссылка, callback, запрос контакта
- `Рассылка`: персональные тексты по списку, отчёт в `ТаблицаЗначений`
- `ПолучитьСобытия`: long polling для регламентного задания; `ОтветитьНаНажатие`
- Ретраи на `429`, `5xx` и `attachment.not.ready` с экспоненциальной паузой
- Учтены особенности API: домен `platform-api2.max.ru`, токен только в заголовке `Authorization`, ответы `200 + success:false`, лимит 2 сообщения/сек в чат
- Ошибки пишутся в журнал регистрации (`MAX.API`)

## Установка

1. Создайте общий модуль `МаксAPI` (флажок «Сервер»), вставьте `src/CommonModules/МаксAPI/Ext/Module.bsl`.
2. Добавьте сертификат НУЦ Минцифры в доверенные на сервере 1С (этого требует MAX).
3. Получите токен: «MAX для бизнеса» → Чат-боты → ⋮ → Настройки.
4. Храните токен в константе или в безопасном хранилище, но не в коде.

## Быстрый старт

```bsl
Настройки = МаксAPI.НовыеНастройки(Токен);
МаксAPI.ОтправитьСообщение(Настройки, МаксAPI.ПолучательПользователь(123456789), "Привет из 1С");
```

Остальное: в `examples/Примеры.bsl`.

## Требования

1С:Предприятие 8.3.10+, любая конфигурация (БП, УТ, ЗУП, самописная). Работает в файловом и клиент-серверном режиме.

## Внедрение под ключ

Боты для УК, ТСЖ и селлеров на базе 1С: долг по лицевому счёту, акт сверки по кнопке, рассылки, приём показаний в 1С.
